1. DATABASE INTEGRITY
============================================================

Review the current PostgreSQL/Drizzle schema.

Do NOT reset or recreate the database.

Create proper migrations.

The most important requirement is database-level duplicate protection.

Photos/assets must have a unique constraint equivalent to:

UNIQUE(user_id, hash)

This prevents race conditions when multiple import workers process the same file simultaneously.

Handle unique constraint conflicts gracefully.

Do not allow two identical assets to be created for the same user.

Also ensure album names cannot race during concurrent creation.

Use an appropriate constraint such as:

UNIQUE(user_id, name)

Use PostgreSQL ON CONFLICT or equivalent safe logic.

Do not rely only on application-level SELECT-then-INSERT logic.
